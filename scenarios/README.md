# سيناريوهات الاختبار

ملف لكل صفحة: `<رقم>-<الصفحة>.md`. وكل سيناريو مكتوب بالشكل ده:

| # | الخطوة (اضغط / أدخل) | المتوقع | الفعلي | النتيجة | الدليل |
|---|---|---|---|---|---|
| 1 | … | … | (بيتملي وقت الاختبار) | عدّى / وقع | صورة أو نص |

- **طبيعي:** الاستخدام العادي بيانات صح.
- **استثنائي:** بيانات ناقصة أو غلط، أو دور ممنوع، أو تكرار.
- **التأثير:** الإجراء ظهر فين تاني (تقارير، مالية، تتبع…).

أي «وقع» = صف جديد في `trace.csv`.
